# =============================================================================
# Zaha — API de inferencia (PRODUCCIÓN)
#
# Esto es lo único que se instala en el contenedor de Hugging Face Spaces.
# Deliberadamente NO incluye torch ni jupyter: el Space sirve un modelo ONNX
# ya entrenado, no entrena nada. Meter torch acá agregaría ~2 GB al contenedor
# y minutos de arranque en frío, que es justo lo que ADR-004 quiso evitar.
#
# Para trabajar en notebooks y entrenar, usar requirements-dev.txt.

# El Space usa el SDK de Gradio porque Docker Spaces paso a ser de pago. Gradio monta
# la misma app de FastAPI (ver deploy/hf_space/app.py); no la reemplaza. Arrastra mas
# dependencias de las que esta API necesita --pandas entre ellas-- y ese es el costo de
# no tener Docker.
gradio~=6.30.0

fastapi~=0.141.1
uvicorn~=0.52.4
# NO SUBIR ESTE TECHO SIN MIRAR GRADIO. El Space de Hugging Face no instala solo
# nuestro requirements.txt: le agrega `gradio[oauth,mcp]`, y el extra `mcp` exige
# pydantic<=2.12.5. Un `~=2.13.4` aca hace que el build falle con ResolutionImpossible,
# y el error aparece en el log de construccion del Space, no en ninguna prueba local.
pydantic>=2.11,<2.13

# Runtime de inferencia. Sin torch: el modelo viaja en ONNX.
onnxruntime~=1.29.0
numpy~=2.5.2
